Android APK Native Readiness & Offline Guarantees 100% VERIFIED

ThrottleLog is engineered as a standalone, zero-telemetry motorcycle flight recorder. When packaged as an Android APK via Capacitor, the application boots completely offline directly from the device's local asset bundle (dist/), utilizing local IndexedDB for perpetual storage, WebCrypto for passwordless AES-GCM vault security, and MQTT WebSocket messaging for peer convoy radar.

Complete Technology Stack

Core Application Layer UI / Framework

Ultra-responsive, glove-optimized interface built with modern web technologies.

  • React 19: State synchronization, concurrent transitions, zero re-render lag during 1Hz GNSS fixes.
  • Vite: Native ESM compilation and ultra-fast asset bundling.
  • Tailwind CSS v4 & Vanilla CSS Tokens: Dynamic dark cockpit filter, high-contrast sunlight mode, and 48px glove touch targets.
  • Motion (Framer Motion 12): Hardware-accelerated lean horizon animation and spring-damped HUD drawers.

Mapping & Cartography Engine GIS / Tiles

Independent map rendering designed for remote mountain passes and zero-cell zones.

  • Leaflet 1.9.4: High-performance tile rendering with vector polyline overlays.
  • Active Course-Up Rotation: Dynamic 150% oversized viewport transform with text counter-rotation and stopped-heading retention.
  • Offline Tile Engine: Pre-caches 1,500 OSM and Esri satellite tiles into CacheStorage for offline riding.
  • Speed Color-Coded Polylines: Dynamic HSL gradient rendering across 10–120+ km/h speed chunks.

Telemetry & Sensor Fusion Sensors

Mathematical decomposition of smartphone IMU accelerometer and gyroscope data.

  • 3D Vector Lean Fusion: Euler rotation matrix with centrifugal compensation separating body lean from motorcycle cornering.
  • Crash & Impact Detection: Multi-stage filter requiring >18 km/h riding + >6.5G impact spike + abrupt stationary stop >4s.
  • GNSS Deadband Filter: Speed spike clamping (>14 m/s²), 1.5m jitter suppression, and multi-tier forward bearing determination.

Squad Radar & Real-Time Sync Connectivity

Decentralized convoy communication without user accounts or central databases.

  • MQTT over WebSockets: Low-bandwidth, low-power telemetry broadcasts across squad room codes.
  • Critical Disconnect Queue: In-memory buffer guaranteeing emergency SOS pings, route shares, and voice notes deliver upon reconnect.
  • PTT Voice Blast: Web Audio squelch synthesis with Opus audio recording and auto-ducking Bluetooth intercom focus.
